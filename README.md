# BPBD Kebumen Web Replication

**BPBD Kebumen Web Replication** is a frontend web project that replicates the user interface of the **BPBD Kabupaten Kebumen** website using **ReactJS** and **Bootstrap**.

The project focuses on recreating the website layout and interface through a structured component-based architecture while maintaining responsive behavior and reusable UI elements.

## 🌐 About the Project

This project was developed as a replication of the BPBD Kabupaten Kebumen website interface.

ReactJS is used to structure the application into reusable components, while props are implemented to manage and distribute data between components. Bootstrap provides the responsive layout and interface styling across different screen sizes.

## 🧩 Component Architecture

The application is structured using reusable React components to maintain a modular and organized codebase.

Props are used to pass data between components, allowing similar interface elements to be reused while displaying different content.

## 📱 Responsive Design

The interface is designed to adapt across different screen sizes using Bootstrap's responsive layout system.

This approach helps maintain consistent spacing, structure, and interface behavior across desktop and mobile devices.
